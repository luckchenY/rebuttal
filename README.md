compiled separately; it is not included by main.tex.

## Edit together in Overleaf

- Use main.tex as the main document and pdfLaTeX as the compiler.
- If the Overleaf project is already linked to luckchenY/rebuttal, pull the
  GitHub changes from the project's GitHub synchronization controls.
- Alternatively, create an Overleaf project by importing the supplied source ZIP.
- Edit the corresponding reviewers/reviewerN.tex file for each reviewer.
- Write each point-by-point reply inside the blue responsebox beneath the
  relevant weakness (W1, W2, ...) or rebuttal question (Q1, Q2, ...).
- Write the final consolidated reply to each official reviewer in that review's
  green Final Response for Submission box.
- Replace the spacing command inside a blank box with your own response text.
- To consult the previous filled draft, open draft-with-existing-responses.tex.
